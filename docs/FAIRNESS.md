# 抽样规则（1.0.5）

服务端从当前待抽名单中使用 Node.js `crypto.randomInt(剩余人数)` 选取一人，移出候选池，再继续选下一人。每次选择时每个候选工号概率相同；一次抽取 k 人时，每个候选人的入选概率为 k/N。API 说明见 [Node.js 官方文档](https://nodejs.org/api/crypto.html#cryptorandomintmin-max-callback)。

所有奖项的已中奖工号均从候选池排除，单次、跨轮和跨奖项均不能重复。未到场后补抽的原中奖人也会被排除。候选人数不足时限制本轮数量，不自动重置奖池。

前端、模板和服务端均不提供权重、指定中奖人或重复中奖功能；旧配置中的这些字段被忽略并清理，接口拒绝重新启用。旧名单只保留前四列，新导入中有额外非空列会被拒绝。结果导出没有权重列。

大屏仅展示一部分人员供预览，不影响服务端完整候选池。动画、拖动、翻页和点击停止的时机不会传入指定中奖工号。

以唯一工号识别人，正式名单需确保一人一号。管理员仍可修改名单、重置活动或修改源码；本说明描述当前代码规则，不代表外部审计或防管理员篡改认证。现场应在抽取前确认名单，并保留结果备份。
